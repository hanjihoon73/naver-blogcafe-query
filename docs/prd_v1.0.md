# 제품 요구사항 정의서 (PRD) - v1.0

## 1. 개요 (Overview)
사용자가 특정 키워드를 입력하면, 네이버 블로그와 카페의 검색 결과를 수집하여 데이터를 분석하는 웹 서비스입니다. 수집된 데이터를 바탕으로 월별 트렌드, 콘텐츠 종류, 사람들의 긍정/부정(감성) 반응을 한눈에 파악할 수 있는 대시보드를 제공합니다.

## 2. 제품 목표 (Goals)
- **효율적인 정보 수집**: 번거로운 수작업 검색 없이, 한 번의 키워드 입력으로 네이버 블로그/카페 데이터를 자동으로 모아줍니다.
- **직관적인 분석 인사이트 제공**: 단순한 검색 결과 나열이 아닌, 월별 언급량, 콘텐츠 카테고리(예: 리뷰, 정보성, 일상 등), 감성 분석(긍정/부정) 등 마케터나 기획자가 즉시 활용할 수 있는 형태의 인사이트를 제공합니다.

## 3. 타겟 사용자 (Target Audience)
- 트렌드 파악 및 시장 조사가 필요한 마케터 및 기획자
- 자사 브랜드나 제품에 대한 대중의 반응을 모니터링하려는 서비스 담당자

## 4. 주요 기능 요구사항 (Key Features)

### 4.1. 키워드 검색 기능
- 분석하고자 하는 '키워드'를 입력하고 검색 버튼을 누를 수 있는 화면.
- 최근 검색어나 인기 검색어를 보여주는 기능 (추후 확장 고려).

### 4.2. 데이터 수집 (Naver Blog & Cafe)
- 네이버 블로그 및 카페에서 해당 키워드가 포함된 게시글의 제목, 등록일, 요약 내용 등을 수집합니다.

### 4.3. 데이터 분석 (AI/포맷팅)
- **월별 트렌드**: 수집된 게시글의 날짜 데이터를 바탕으로, 각 월별 새롭게 등록된 글의 수를 계산하여 보여줍니다.
- **콘텐츠 종류 분류**: 게시글 내용을 분석하여 리뷰, 정보 제공, 홍보, 일상 글 등으로 자동 분류합니다.
- **긍/부정 반응 분석**: 글의 뉘앙스를 파악하여 긍정적, 부정적, 중립적 반응으로 수치화합니다.

### 4.4. 대시보드 (결과 리포트 화면)
- 분석 결과를 차트(그래프)와 요약 차원으로 시각화하여 보여줍니다 (예: 파이 차트, 막대 그래프 등).
- 수집된 원본 게시글 목록을 표 형태로 함께 제공하여 상세 내용을 클릭해 볼 수 있게 합니다.

## 5. 비기능적 요구사항
- **가벼움과 속도**: 데이터 수집과 분석이 완료될 때까지 사용자가 지루하지 않도록 로딩 UI를 친절하게 제공해야 합니다.
- **반응형 웹**: PC 환경뿐 아니라 모바일 환경에서도 대시보드가 깨지지 않고 잘 보이게 구성해야 합니다.
- **쉬운 UI/UX**: 복잡한 통계 툴처럼 보이지 않고, 누구나 직관적으로 결과를 읽을 수 있도록 깔끔한 디자인(바닐라 CSS 활용 등)을 적용해야 합니다.
