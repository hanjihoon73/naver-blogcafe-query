# 소셜 데이터 분석기 PRD (Product Requirements Document) v1.2

## 1. 개요
* 프로젝트명: 소셜 데이터 분석기 (Social Analysis)
* 대상 사용자: 네이버 블로그 및 카페의 게시물 건수를 분석하여 마케팅/동향을 파악하고자 하는 비즈니스/마케팅 담당자
* 변경 목표: 검색 기간이 1개월을 초과하는 장기 분석의 경우, 전체 합계뿐만 아니라 월별 트렌드를 파악할 수 있도록 데이터 집계 로직 및 UI를 개선하고 결과를 엑셀로 다운로드할 수 있는 기능을 추가합니다.

## 2. 주요 기능 및 요구사항 변경 사항
### 2.1. 월별 게시물 건수 집계 기능
* **기존 동작**: 시작일(startDate)과 종료일(endDate) 사이의 '전체 합계'만 보여줌.
* **신규 동작**: 
  * 검색된 기간이 '1개월 초과'(예: 서로 다른 월이 2개 이상 포함)일 경우, 백엔드에서 해당 기간을 월 단위로 나누어 데이터를 수집/집계합니다.
  * 프론트엔드에서는 전체 총 건수와 함께, 하단에 월 구분 별 블로그/카페 건수가 표시된 상세 테이블 형식의 목록을 노출합니다.
  * 검색 기간이 1개월 이하(같은 월 내)일 때는 기존처럼 총 합계 화면만 심플하게 표시합니다.

### 2.2. 엑셀 다운로드 기능
* **요구사항**: 분석 결과를 로컬 PC용 엑셀(Excel, .xlsx) 파일로 내보낼 수 있어야 합니다.
* **기능 상세**:
  * 데이터 조회가 완료된 화면 상단(또는 결과 테이블 근처)에 '엑셀로 저장(다운로드)' 버튼을 노출합니다.
  * 엑셀 파일에는 검색 키워드, 검색 전체 기간, 전체 합계 건수 정보와 함께, 월별 조회가 이루어졌다면 월별 블로그 및 카페 세부 건수 테이블이 포함되도록 구성합니다.
  * 사용자가 추가 작업 없이 버튼 클릭 한 번으로 즉시 다운로드 되도록 합니다.

## 3. 비기능적 요구사항
* **안정성 (Stability)**: 대량의 크롤링을 처리할 때 월별로 분할해서 순차 처리하므로 안정성을 높이고, Puppeteer의 브라우저 타임아웃 오류를 최소화하도록 딜레이를 고려합니다.
* **직관성 (Usability)**: 월별 데이터 결과는 가독성이 높은 디자인(표 또는 리스트)으로 구성하며 비개발자도 한눈에 파악하기 쉽게 제공합니다.
