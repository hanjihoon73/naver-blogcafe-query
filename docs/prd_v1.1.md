# 제품 요구사항 정의서 (PRD) - v1.1

## 1. 개요 (Overview)
사용자가 특정 키워드를 입력하면, 네이버 블로그와 카페의 게시글 및 댓글 검색 결과를 수집하여 데이터를 분석하는 내부용 웹 서비스입니다. 초기 버전은 '깨봉수학' 키워드에 한정하여 데이터를 수집하며, 월별 데이터 건수 및 긍정/부정 비율을 시각화하고 엑셀로 다운로드할 수 있는 대시보드를 제공합니다.

## 2. 제품 목표 (Goals)
- **효율적인 정보 및 평판 수집**: 번거로운 수작업 검색 없이, '깨봉수학'에 대한 네이버 블로그/카페의 게시글뿐만 아니라 **댓글 반응**까지 자동으로 모아줍니다.
- **직관적인 분석 및 추출**: 별도의 DB 없이 검색된 결과를 즉시 분석하여 월별 트렌드와 긍/부정 비율을 파악하고, 원본 데이터를 엑셀로 쉽게 내보낼 수 있도록 합니다.

## 3. 타겟 사용자 (Target Audience)
- 깨봉수학 내부 서비스 및 마케팅 지표 분석 담당자

## 4. 주요 기능 요구사항 (Key Features)

### 4.1. 키워드 검색 기능 (초기 고정)
- 검색 키워드는 내부용인 **'깨봉수학'**으로 우선 고정되어 동작합니다. 추후 다른 키워드 입력 방식으로 전환할 수 있는 구조를 열어둡니다.

### 4.2. 데이터 조회 조건 및 수집 (Naver Blog & Cafe)
- 지정한 **월별** 기간 단위로 데이터를 조회합니다.
- 수집해야 하는 필수 데이터 항목:
  - 블로그 포스트 건수
  - 블로그 포스트의 긍정/부정 비율
  - 해당 포스트의 댓글 건수
  - 포스트 댓글의 긍정/부정 비율
  - 카페 게시글 건수
  - 카페 게시글의 긍정/부정 비율
  - 해당 게시글의 댓글 건수
  - 게시글 댓글의 긍정/부정 비율

### 4.3. 데이터 분석 (AI 감성 분석)
- 게시글 본문 및 댓글의 텍스트를 분석하여 각각의 긍/부정(Sentiment) 비율을 도출합니다.

### 4.4. 대시보드 및 내보내기 
- 분석 결과를 월별 트렌드 차트 및 표 형태로 시각화하여 보여줍니다.
- 조회된 대상 데이터를 **엑셀 파일 형태(.xlsx)로 다운로드**하는 기능을 제공합니다.
- 데이터베이스(DB) 저장을 생략하고, 매 조회 시 혹은 메모리 내 캐싱을 통해 결과를 휘발성으로 화면에 제공하고 다운로드로 영구 보관을 대체합니다.

## 5. 비기능적 요구사항
- **응답 대기 UX**: 블로그/카페의 본문과 댓글을 모두 탐색하고 분류하는 작업은 시간이 소요되므로, 사용자에게 명확한 진행 상황(로딩바, 스피너 등)을 안내해야 합니다.
- **쉬운 UI/UX**: 복잡한 통계 툴처럼 보이지 않고, 누구나 직관적으로 결과를 읽고 엑셀 리포트로 뽑아낼 수 있도록 깔끔한 디자인(바닐라 CSS 활용 등)을 적용해야 합니다.
